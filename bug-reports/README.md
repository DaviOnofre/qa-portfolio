# QA Portfolio - Bug Reports

Este repositório reúne exemplos de relatórios de bugs elaborados durante estudos e projetos de QA, seguindo boas práticas de documentação para facilitar a reprodução, análise e correção de defeitos.

## Objetivo

Demonstrar a capacidade de:

- Identificar falhas em aplicações
- Documentar bugs de forma clara e objetiva
- Informar passos para reprodução
- Definir resultado esperado e resultado obtido
- Classificar severidade e prioridade
- Organizar evidências para a equipe de desenvolvimento

## Estrutura

```
bug-reports/
├── BUG-001.md
├── BUG-002.md
├── BUG-003.md
└── ...
```

## Modelo de Bug Report

Cada relatório contém informações como:

- ID do Bug
- Título
- Ambiente
- Pré-condições
- Passos para reprodução
- Resultado esperado
- Resultado obtido
- Severidade
- Prioridade
- Evidências (prints, vídeos ou GIFs)

## Ferramentas

- Markdown
- GitHub
- Playwright (para reproduções quando aplicável)
- Capturas de tela
- Gravações de vídeo

## Objetivo do Projeto

Este projeto faz parte do meu portfólio como Analista de QA e tem como finalidade demonstrar minhas habilidades em identificação, documentação e comunicação de defeitos durante o processo de garantia da qualidade de software.
